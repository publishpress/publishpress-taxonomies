# Show the Terms Display in a Widget

With Taxonomies, you can create a Terms Display layout and show it in a WordPress widget.

Go to Appearance > Widget and look for the “Term Display (Taxonomies Shortcode)” widget. This can be placed in any area that your theme has available.
