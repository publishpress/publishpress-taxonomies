# Media Tags

[PublishPress Taxonomies](https://publishpress.com/links/taxonomies) provides a “Media Tags” taxonomy so you can organize your Media Library.

You can edit the settings for Media Tags by visiting [the “Taxonomies” screen](https://publishpress.com/knowledge-base/introduction-taxonomies-screen/). You can see this taxonomy under the “Media” menu in your WordPress dashboard.

![Media Tags in the TaxoPress plugin](https://docs-media.publishpress.com/publishpress-taxonomies/media-tags-d1eaac17b4.webp)

You can add tags to your media files by editing any file in the Media Library. The image below shows the “Media Tags” box.

![Adding tags to Media images](https://docs-media.publishpress.com/publishpress-taxonomies/media-tags-add-b743d14fd7.webp)
