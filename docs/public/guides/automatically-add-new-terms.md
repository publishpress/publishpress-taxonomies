# Automatically Add New Terms (Pro)

Table of Contents

- [An example of automatically adding new terms](#0-toc-title)
- [How does this Auto Terms feature work?](#1-toc-title)

This feature requires the Pro version of the Taxonomies plugin

Taxonomies has a feature that can analyze your content and automatically add new terms. This will be very useful for anyone who creates a lot of content.

This feature works by integrating with OpenAI, IBM Watson, Dandelion or Open Calais systems to scan content and create terms.

## An example of automatically adding new terms [#](#0-toc-title)

Let’s see an example of how this feature works. I’ve created a new post, using the text from the “About Us” page on WordPress.org.

![About page from WordPress.org](https://taxopress.com/wp-content/uploads/2022/01/new-post-auto-terms-1024x703.png)

When I publish this post, Taxonomies scans the post and adds new terms, as you can see in the image below:

![Automatic terms generated by TaxoPress for About page from WordPress.org](https://taxopress.com/wp-content/uploads/2022/01/post-ideas-1024x376.png)

This feature can work with any taxonomy and post type. For example, in the image below, I have a WooCommerce product. Taxonomies has scanned the content and added new terms into the “Product tags” area.

![Automatic terms generated by TaxoPress for WooCommerce](https://taxopress.com/wp-content/uploads/2022/01/yoga-mat-1024x535.png)

In the next screenshot, you can see an example with bbPress. In this example, Taxonomies used the Auto Terms feature to scan a new bbPress topic and automatically added new terms to the “Topic Tags” area.

![Automatic terms generated by TaxoPress for bbPress](https://taxopress.com/wp-content/uploads/2022/01/bbpress-automatic-terms-1024x461.png)

## How does this Auto Terms feature work? [#](#1-toc-title)

This Auto Terms feature to add new terms is built on top of external services. OpenAI is the default option. You can also enable IBM Watson, Dandelion, and LSEG/Refinitiv via the “Settings” area of Taxonomies. The option to use these services is available only in Taxonomies Pro.

![Automatic terms generated by TaxoPress in Auto Terms](https://docs-media.publishpress.com/publishpress-taxonomies/auto-terms-openai-only-194c73c041.webp)

*auto terms openai only*

Once you have an API key for OpenAI or another service, go to “Taxonomies”, then “Auto Terms” in your WordPress admin menu. You can enter your API key here on the “Sources” tab.

![OpenAI Key in TaxoPress in Auto Terms](https://docs-media.publishpress.com/publishpress-taxonomies/openai-key-91385309bd.webp)
