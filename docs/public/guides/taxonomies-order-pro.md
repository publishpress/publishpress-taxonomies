# Taxonomies: Order (Pro)

Table of Contents

- [Default Order for Tags and Categories](#0-toc-title)
- [Custom Order for Tags and Categories](#1-toc-title)

This feature requires the Pro version of the Taxonomies plugin

In the Pro version of [PublishPress Taxonomies](https://publishpress.com/links/taxonomies), it’s possible to customize the order that terms show.

## Default Order for Tags and Categories [#](#0-toc-title)

In the screenshots below you can see a list of Categories for US States. These Categories are sorted alphabetically in the WordPress admin area and on the front of your site. In this example, the alphabetical order makes some sense, but it can’t be changed.

![Categories in alphabetical order](https://taxopress.com/wp-content/uploads/2025/07/az-states-1024x393.jpg)

*az states*

The same is true for Tags also. In this next screenshot we have some Tags that refer to food. These are sorted alphabetically again. There’s no alternative.

![Tags in alphabetical order](https://taxopress.com/wp-content/uploads/2025/07/az-fruit-1024x257.jpg)

*az fruit*

However, there are times where alphabetical order just doesn’t work. Let’s take the example of timezones. In these next screenshots, you can see the timezones are ordered alphabetically. But this leads to them being displayed in a useless order.

![Timezones display of Categories](https://taxopress.com/wp-content/uploads/2025/07/timezones-1024x369.jpg)

*timezones*

Here’s another example of where alphabetical order doesn’t work. This is from a magazine that uses Tags to assign posts to different issues.

![Tags for Issues in WordPress](https://taxopress.com/wp-content/uploads/2025/07/issues-order-1024x261.jpg)

*issues order*

## Custom Order for Tags and Categories [#](#1-toc-title)

This Taxonomies Pro feature can control the order of Tags and Categories. The order you choose will display when you’re editing posts, and in frontend displays.

Go to the “[Taxonomies](https://taxopress.com/docs/taxonomies-admin-area/)” screen and choose the taxonomy you want to order. There are five choices:

- ID
- Name
- Counter
- Random
- Term Order

![Custom taxonomy order](https://taxopress.com/wp-content/uploads/2025/07/order-taxonomy-1024x516.png)

*order taxonomy*

If you click on the “Taxonomy Terms Table” you’ll be to reorder your terms using a drag-and-drop interface.

![Reorder your terms using a drag-and-drop interface](https://taxopress.com/wp-content/uploads/2025/07/drag-drop-order-1024x710.png)

*drag drop order*

This “Term Order” feature is also available throughout the plugin. For example, in the “[Terms Display](https://publishpress.com/knowledge-base/introduction-to-tag-clouds/)” feature, you can now choose to sort the terms using the order. As you can see in this screenshot below, we’ve solved the problem with the magazine issue numbers.

![Custom taxonomy order in Terms Display](https://taxopress.com/wp-content/uploads/2025/07/term-order-term-display-1-1024x590.png)

*term order term display*
