# Taxonomies: Deactivate or Delete

This guide will show you how to remove or deactivate taxonomies. You can find this by visiting [the Taxonomies screen](https://publishpress.com/knowledge-base/introduction-taxonomies-screen/) and editing a taxonomy.

Please note that this feature is limited in several ways:

- You can not delete the Tags and Categories taxonomies because they are core features of WordPress.
- You can not delete taxonomies from a third party plugin such as WooCommerce.

For these special taxonomies, you can only click “Deactivate Taxonomy” as in the screenshot below. You will see a message saying “[PublishPress Taxonomies](https://publishpress.com/links/taxonomies) has been successfully deactivated”. You will then see a button saying “Re-activate Taxonomy”.

![The "Deactivate Taxonomy" button](https://docs-media.publishpress.com/publishpress-taxonomies/delete-30f2c3ec8a.webp)

For any taxonomy that you created with [PublishPress Taxonomies](https://publishpress.com/links/taxonomies), you will have the option to deactivate or delete the taxonomy.

![The "Deactivate Taxonomy" and "Delete Taxonomy" buttons](https://docs-media.publishpress.com/publishpress-taxonomies/deactivate-b392e1850e.webp)

If you click “Delete Taxonomy”, PublishPress Taxonomies will ask to confirm your decision:

![Box asking to confirm that you want to delete this.](https://docs-media.publishpress.com/publishpress-taxonomies/taxopress-confirm-delete-99fbc8fe8f.webp)
