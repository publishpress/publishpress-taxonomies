# Add CSS to Terms for Current Post

In Taxonomies you can [change the format of your Terms for Current Post display](https://publishpress.com/knowledge-base/format-terms-current-post/). You can also add your CSS to the display of terms.

Go to Taxonomies > Current Post > Advanced and you can add your CSS to the whole div or to specific links. You can do this using the settings below:

![Add CSS to Terms for Current Post](https://docs-media.publishpress.com/publishpress-taxonomies/terms-current-css-cf7a8a23af.webp)

Here is an example of adding classes to these two fields:

![Add CSS to Terms for Current Post](https://docs-media.publishpress.com/publishpress-taxonomies/display-classes-4bfae3cc25.webp)

I can then add the CSS for those classes to my theme, or to the “Customize” feature of WordPress.

![](https://docs-media.publishpress.com/publishpress-taxonomies/terms-display-css-1-bb5637da5a.webp)
