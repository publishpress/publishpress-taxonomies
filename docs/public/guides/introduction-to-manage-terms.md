# Introduction to Manage Terms

The “Manage Terms” screen in Taxonomies provides you with several useful tools to manage the terms on your site.

![Manage terms tabs](https://taxopress.com/wp-content/uploads/2021/02/manage-terms-tabs-1024x578.png)

*manage terms tabs*

These tools can be used with any taxonomy. In the image below, I’m switching between using Tags and Categories:

![Dropdown of Tags and Categories](https://taxopress.com/wp-content/uploads/2021/03/Screen-Shot-2021-03-09-at-10.58.15-AM-1024x153.png)

Here are some of the tasks you can perform on the “Manage Terms” screen:

- [](https://taxopress.com/docs/add-terms/)[Add terms](https://taxopress.com/docs/add-terms/)
- [Remove terms](https://publishpress.com/knowledge-base/remove-terms-tab/)
- [](https://taxopress.com/docs/rename-merge-terms/)[Rename terms](https://publishpress.com/knowledge-base/rename-terms/)
- [](https://taxopress.com/docs/rename-merge-terms/)[Merge terms](https://publishpress.com/knowledge-base/merge-terms/)
- [](https://taxopress.com/docs/rename-merge-terms/)[Delete unused terms](https://publishpress.com/knowledge-base/remove-rarely-used-terms/)
