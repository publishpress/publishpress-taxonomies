# Add CSS to Your Related Posts

In [PublishPress Taxonomies](https://publishpress.com/links/taxonomies) you can [change the format of your Related Posts](https://publishpress.com/knowledge-base/format-related-posts/). You can also add your CSS to the display of your related posts.

Go to Taxonomies > Related Posts > Advanced and you can add your CSS to the whole div or to specific links. You can do this using the settings below:

![Related Posts div class](https://docs-media.publishpress.com/publishpress-taxonomies/related-posts-css-c72bdbb5cd.webp)

Here is an example of adding classes to these fields:

![Related posts div class with entry](https://docs-media.publishpress.com/publishpress-taxonomies/related-classes-d1c441c361.webp)

You can then add the CSS for those classes to my theme, or to the “Customize” feature of WordPress.

![CSS to modify Related Posts](https://docs-media.publishpress.com/publishpress-taxonomies/terms-display-css-1-bb5637da5a.webp)

In this example below, we’ve added the CSS code from above, and then [loaded Related Posts with a widget](https://taxopress.com/docs/where-to-display-related-posts/). The result is very colorful!

![Related Posts with CSS](https://docs-media.publishpress.com/publishpress-taxonomies/related-css-d9993d5c5d.webp)
