# Delete Unused Terms

Taxonomies has a feature that allows you to quickly remove Terms that are rarely used on your site. This feature works for any WordPress taxonomy.

You will find this feature on the “[Manage Terms](https://publishpress.com/knowledge-base/introduction-to-manage-terms/)” screen in Taxonomies.

- Choose the minimum number of uses for Terms that you will keep. In the example below, any Term that has been used 0, 1, 2, 3 or 4 times will be deleted.
- Click the “Check Terms” button to see how many terms will be deleted.
- Click the “Delete Terms” button to remove the terms.

![](https://docs-media.publishpress.com/publishpress-taxonomies/delete-unused-1024x662-1-1590bf7475.webp)
