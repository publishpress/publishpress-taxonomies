# Metabox Settings

Table of Contents

- [Enabling Metabox Features](#0-toc-title)
- [Extra Display Options in Taxonomies Pro](#1-toc-title)

It’s possible to configure important options for the [PublishPress Taxonomies](https://publishpress.com/links/taxonomies) metaboxes under each post.

## Enabling Metabox Features [#](#0-toc-title)

Go to Taxonomies > Metaboxes > Metabox Settings. There will be settings for “Posts”, “Pages” and other content types.

![Metabox Settings tab](https://taxopress.com/wp-content/uploads/2025/06/metabox-settings-tab-1024x635.png)

*metabox settings tab*

Scroll down the screen and you see options. For example, you can choose to show the number of times each term has been used (“Metabox Show Term Post Count”) or the slug for the term (“Show Term Slug”).

![Metaboxes additional settings](https://taxopress.com/wp-content/uploads/2025/06/access-features-1024x373.png)

*access features*

Further down the screen you can control settings such as minimum and maximum length of terms created.

## Extra Display Options in Taxonomies Pro [#](#1-toc-title)

This feature requires the Pro version of the Taxonomies plugin

With Taxonomies Pro you can customize the [PublishPress Taxonomies](https://publishpress.com/links/taxonomies) metabox. You can use the Taxonomies Pro settings to customize this layout. In this screenshot, we use the “Taxonomy Display” option.

This next screenshot shows a “Checkbox” display. With this display it’s no longer possible to add any more Tags or Categories. The authors can only choose terms that already exist.

![Metabox with checklist in TaxoPress](https://taxopress.com/wp-content/uploads/2025/01/metabox-checkbox-1024x402.png)

*metabox checkbox*

You can customize the appearance of this metabox. For example, this next screenshot shows the same terms, but organized by popularity. You’ll always see the most commonly-used terms on the top of the list.

![Terms organized by popularity in TaxoPress](https://taxopress.com/wp-content/uploads/2025/01/terms-popularity-1024x377.png)

*terms popularity*

This next screenshot shows another way to customize the metabox. You can choose a search box display. This is ideal if you have really large number of terms.

![Metabox with dropdown in TaxoPress](https://taxopress.com/wp-content/uploads/2025/01/metabox-dropdown-1024x375.png)

*metabox dropdown*
