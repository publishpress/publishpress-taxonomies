# Delete Terms

Taxonomies has a feature that allows you to delete taxonomy terms individually or in bulk. This feature works for any WordPress taxonomy. You will find this feature on the “Terms” screen in Taxonomies.

- You can delete single terms by clicking the “Delete” link under the term:

![](https://docs-media.publishpress.com/publishpress-taxonomies/delete-term-3eb29dcfcf.webp)

- You can choose multiple terms to delete at once. Select the terms using the checkboxes on the “Terms” screen.
- Choose the “Delete” option from the dropdown.
- Click the “Apply” button.
- Taxonomies will show the message, “Terms deleted successfully.”

![](https://docs-media.publishpress.com/publishpress-taxonomies/delete-dropdown-c7ec92ef85.webp)
