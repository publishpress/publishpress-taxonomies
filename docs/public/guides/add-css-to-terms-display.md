# Add CSS to Your Terms Display

Taxonomies allows you to [change the format of your Terms Display](https://publishpress.com/knowledge-base/format-tag-clouds/). You can also add your CSS to the display of terms.

Go to Taxonomies > Terms Display > Display Format, and you can add your own CSS class to the whole div or to specific links. You can do this using the settings below:

![Add CSS to Your Terms Display](https://docs-media.publishpress.com/publishpress-taxonomies/terms-display-css-4af89020ea.webp)

Here is an example of adding classes to these fields:

![Add CSS to Your Terms Display](https://docs-media.publishpress.com/publishpress-taxonomies/class-display-9fffe02d9d.webp)

I can then add the CSS for those classes to my theme, or to the “Customize” feature of WordPress.

![](https://docs-media.publishpress.com/publishpress-taxonomies/terms-display-css-1-bb5637da5a.webp)

In the image above, I’ve added the CSS code. Then I included t[he “Terms Display” shortcode](https://taxopress.com/docs/tag-cloud-shortcode/) into a post, and the image below shows the very colorful result!

![Add CSS to Your Terms Display](https://docs-media.publishpress.com/publishpress-taxonomies/display-css-b3a8549c1a.webp)
