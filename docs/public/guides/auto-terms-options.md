# Auto Terms: Options

The Auto Terms feature in Taxonomies has several options that you can configure:

- **Add terms if synonyms found**: This is available in Taxonomies Pro and links to [the Synonyms feature](https://publishpress.com/knowledge-base/synonyms/).
- **Content statuses**: You can choose to run the Auto Terms feature on unpublished or unpublished content
