# Rename Terms

Taxonomies has a feature that allows you to rename taxonomy Terms.

You will find this feature on the “[Manage Terms](https://publishpress.com/knowledge-base/introduction-to-manage-terms/)” screen in Taxonomies. This feature allows you to rename multiple Terms.

In the image below, I want to rename the “CMS” Term to “Content Management System”.

![](https://taxopress.com/wp-content/uploads/2021/03/rename-1024x272.png)

Click “Rename”, and you’ll see a message that shows the renaming was successful:

![](https://taxopress.com/wp-content/uploads/2021/03/rename-result.png)
