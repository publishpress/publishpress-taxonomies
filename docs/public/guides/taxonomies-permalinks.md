# Taxonomies: Permalinks

This guide will show you how to change the “Permalinks” options for your taxonomies. You can find this by visiting [the Taxonomies screen](https://publishpress.com/knowledge-base/introduction-taxonomies-screen/) and editing a taxonomy.

For the Category and Tag taxonomies, plus taxonomies from a third-party plugin such as WooCommerce, the image below shows the screen you will see:

![Taxonomies: Permalinks](https://docs-media.publishpress.com/publishpress-taxonomies/edit-taxonomy-permalinks-28f72df395.webp)

*edit taxonomy permalinks*

For taxonomies created by TaxoPress, this image below shows the screen you will see. The options require you to move more carefully. We do not recommend you change the “Taxonomy Slug” because this will create a new taxonomy.
