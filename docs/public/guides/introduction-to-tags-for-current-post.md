# Introduction to Terms for Current Post

Table of Contents

The “Current Post” feature in Taxonomies allows you to customize the displays of terms for single posts.

You access this feature in your WordPress dashboard by going to Taxonomies > Current Post.

## Example of Terms for Current Post [#](#0-toc-title)

The image below shows an example of Terms for Current Post. This display is separate from any default display of terms in your theme. The image below shows the terms created by the Taxonomies “Current Post” feature on a post.

![Terms for Current Post](https://docs-media.publishpress.com/publishpress-taxonomies/related-posts-2-d51a1b68bc.webp)

## Edit or Add New Terms for Current Post [#](#1-toc-title)

On the “Current Post” screen, you’ll see all your displays. You can click the title or the “Edit” link to edit the settings for this existing display.

![Terms for Current Post](https://docs-media.publishpress.com/publishpress-taxonomies/terms-current-post-74a774cdbc.webp)

*terms current post*

This feature requires the Pro version of the Taxonomies plugin

On the “Current Post” screen in the Pro version of Taxonomies Pro, you can click “Add New” and add your own display.
