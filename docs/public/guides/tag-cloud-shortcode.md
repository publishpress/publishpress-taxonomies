# Show the Terms Display with a Shortcode

[PublishPress Taxonomies](https://publishpress.com/links/taxonomies) allows you to show a cloud or list of the terms in a taxonomy. You can show your terms using the shortcode shown on the “Terms Display” screen:

![Show the Terms Display with a Shortcode](https://docs-media.publishpress.com/publishpress-taxonomies/terms-display-2-060ba7acf5.webp)

If you are using the block editor in WordPress, you can also add Taxonomies shortcodes using the “Shortcode” block. In the image below, I’ve added a shortcode block:

![Show the Terms Display with a Shortcode](https://docs-media.publishpress.com/publishpress-taxonomies/shortcode-block-2b9025f553.webp)

The image below shows the output from the block above. The cloud appears under the main text of the post:

![Show the Terms Display with a Shortcode](https://docs-media.publishpress.com/publishpress-taxonomies/tag-cloud-shortcode-41e07a0a05.webp)
