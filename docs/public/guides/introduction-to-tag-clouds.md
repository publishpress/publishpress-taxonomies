# Introduction to Terms Display

Table of Contents

- [Example of Terms Display](#0-toc-title)
- [Edit or Add New Term Displays](#1-toc-title)
- [Editing Term Displays](#2-toc-title)

The Terms Display feature in [PublishPress Taxonomies](https://publishpress.com/links/taxonomies) allows you to create a customizable display of all the terms in one taxonomy. With such a terms display you can show a cloud or list of the terms used on your site. For example, you can create a “Tag Cloud” showing all your WooCommerce product categories, or you can create a list of all the tags on bbPress topics.

## Example of Terms Display [#](#0-toc-title)

The image below shows an example of Terms Display. The most frequently used terms are shown in a larger, darker font and less popular terms are shown smaller and lighter.

![Terms Display example](https://docs-media.publishpress.com/publishpress-taxonomies/tag-cloud-0540a9359e.webp)

## Edit or Add New Term Displays [#](#1-toc-title)

On the “Terms Display” screen, you’ll see all your term displays. You can click the title or the “Edit” link to edit the settings for this existing display.

![Terms Display Screen](https://docs-media.publishpress.com/publishpress-taxonomies/terms-display-add-new-6f7b058fd7.webp)

*terms display add new*

This feature requires the Pro version of the Taxonomies plugin

On the “Terms Display” screen in the Pro version of Taxonomies Pro, you can click “Add New” and add your own display.

## Editing Term Displays [#](#2-toc-title)

Inside each display you will find a preview, and a large number of customization options, as shown in this screenshot below.

![Manage Terms Display](https://docs-media.publishpress.com/publishpress-taxonomies/manage-terms-display-4a04852eae.webp)

*manage terms display*
