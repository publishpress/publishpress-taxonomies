# Taxonomies: REST API

This guide will show you how to change the “REST API” options for your taxonomies. You can find this by visiting [the Taxonomies screen](https://publishpress.com/knowledge-base/introduction-taxonomies-screen/) and editing a taxonomy.

These options allow you to expose your taxonomy data in the WordPress REST API:
